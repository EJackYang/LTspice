# 『回路シミュレータLTspiceで学ぶ電子回路（第4版）』ダウンロードデータ

本の中で取り上げたサンプル回路例を、章ごとのフォルダーに格納しています。
基本的には、図のキャプションのあとに「Sample」アイコンがあるものを格納していますが、参考資料として、必ずしもアイコンがない回路も用意しています。

Sample回路ファイル名は「Fig_<章番号>-<図番号>_<回路の意味>.asc」のように表記しています。
一つの図に対応する資料（回路図やサブ・サーキットなど）が多い場合には、図番号のついたフォルダーにまとめて格納しました。

拡張子「.asc」はLTspice用回路図フォーマットで、「.plt」はその回路のプロット表示用のファイルです。
「.plt」がある回路図は、シミュレーションの実行とともに、グラフ表示を行います。「.plt」ファイルがないSample回路図は、グラフペインを表示した後、回路中のノード電圧や素子の電流をプローブすることで波形表示します。
ファイル名の<回路の意味>は、部品番号や回路構成などで、ファイル検索の補助にするためにつけています。

なお、Sample回路図は本文中の図版と完全に一致していない場合がありますが、パラメータなどを書き換えることで、図版と同様の動作をするようになっています。
